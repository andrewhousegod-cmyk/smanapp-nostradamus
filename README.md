# SmanApp NOSTRADAMUS Dashboard

Dashboard predittiva enterprise per analisi business SmanApp con funzionalità avanzate di forecasting, risk scoring e AI insights.

## 🚀 Features

### ✅ Implementate
1. **YoY Comparisons** - Tutti i KPI con confronto anno precedente
2. **Trend Arrows & Delta** - Indicatori visuali su ogni metrica
3. **Risk Scoring** - Algoritmo predittivo partner a rischio
4. **Cohort Analysis** - Retention per anno acquisizione
5. **CLV Segmentation** - Segmentazione per valore cliente
6. **Forecasting Statistico** - Previsioni trend con confidence interval
7. **Goal Tracking** - Progress bars obiettivi 2025
8. **Alert System** - Alert automatici su KPI critici
9. **Filtri Globali** - Anno, mese, operatore
10. **Export CSV** - Da tutte le tabelle

## 📊 Sezioni Dashboard

1. **🔮 Executive Overview** - Vista strategica + forecasting
2. **🔴 Retention Intelligence** - Risk scoring + cohort analysis
3. **💰 Sales Operations** - CLV segmentation + performance
4. **💵 Financial Control** - Goal tracking + cashflow
5. **🗺 Market Intelligence** - Analisi geografica + opportunità
